# `sima-cli cloudex update`

Install or update the native CloudEx forwarder.

Parent command: [`sima-cli cloudex`](./sima-cli-cloudex.md)

## Usage

```bash
sima-cli cloudex update [OPTIONS]
```

## Options

| Name | Description |
| --- | --- |
| `--branch` | Kerrigan branch whose latest forwarder should be installed. (default: develop) |

## Arguments

None.

## Full Help

```text
Usage: sima-cli cloudex update [OPTIONS]

  Install or update the native CloudEx forwarder.

Options:
  --branch TEXT  Kerrigan branch whose latest forwarder should be installed.
                 [default: develop]
  --help         Show this message and exit.
```
