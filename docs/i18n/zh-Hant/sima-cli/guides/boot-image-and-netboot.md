# 開機映像與網路開機操作

使用 `sima-cli bootimg` 準備本機或下載的映像、安全設定遠端網路開機、處理位址變更，並準備要燒錄的 eMMC。

命令參考：[`sima-cli bootimg`](../../../../sima-cli/commands/sima-cli-bootimg.md)

## 本機映像與快取重複使用

將 `--images DIRECTORY` 與 `--netboot` 或 `--autoflash` 搭配使用，以主機上現有的成品準備網路開機工作階段。目錄會以遞迴方式搜尋。eLxr 需要一個最小 TFTP 封存檔，以及一個相符且非復原用途的 `.img.gz` eMMC 映像。Yocto 需要一個包含 TFTP 檔案及其 `.wic.gz` 和 `.wic.bmap` 映像的版本封存檔。若集合不明確或不完整，會在 TFTP 伺服器啟動前停止。

來源目錄不會被修改。sima-cli 將 TFTP 內容複製並解壓縮至平台暫存目錄下 `sima-cli/netboot` 的受管理快取。當來源識別資訊與準備完成的檔案大小仍相符時，會重複使用快取。下載的網路開機映像也使用相同快取。加入 `--delete-cache`，即可在 TFTP 伺服器停止後，只移除該工作階段的受管理快取。其他工作階段使用中的快取會保留。

## 每日網路開機的備援來源

對內部 Modalix eLxr 3.0+ 建置，`--netboot` 與 `--autoflash` 只有在指定 `-f/--force`，且無法連線至 Artifactory 或驗證失敗時，才使用公開的每日平台鏡像站。未指定 `-f` 時，準備作業會停止並說明如何啟用備援來源。大小與 SHA-256 驗證仍為必要步驟。`-v` 接受精確建置名稱或 `1247`、`3.0`、`develop` 等搜尋字詞；多個符合結果會由新到舊顯示。

最小 TFTP 封存檔、palette `.img.gz` eMMC 映像及 `troot_blob.be` 必須來自同一個選定建置。鏡像站成品若缺失、不相符或無效，會在解壓縮或啟動 TFTP 前停止準備。仍可使用本機檔案、直接 URL、Yocto 與較舊 eLxr 的處理流程。

## 準備遠端網路開機

使用 `--netboot --devkit 192.168.2.2` 選取 DevKit，或省略 `--devkit` 以使用 SDK 探索。若有多個裝置，會提示選取。若找不到裝置，TFTP 仍保持可用，CLI 會印出手動設定指示。`--devkit-ip` 仍可作為別名使用。

裝置必須可透過 SSH 存取，且在 `/boot` 下提供 U-Boot 執行檔及環境檔案。sima-cli 會比對環境格式與開機載入程式、備份目前環境，並在安全可行時轉換不相容的備援環境格式。主機至選定 DevKit 的路由決定 TFTP 伺服器位址，多介面主機亦同。

修改裝置前，確認面板會顯示網路設定、永久 U-Boot 變更及重新開機的影響。預設為「否」。接受後，必要時會暫時將 `/boot` 重新掛載為可寫入，之後恢復原本掛載模式、儲存備份至 `/boot/sima-cli-netboot-backup.*`、設定 `boot_targets=net`、驗證結果並排程重新開機。準備失敗時會還原已儲存的環境並防止重新開機。

平台 2.1.2 及更早版本可能使用無法安全辨識的舊版 `fw_env.config` 配置。此時 sima-cli 會還原備份、保持 TFTP 運作，並印出要透過序列主控台輸入的確切 U-Boot 命令。

保持主機與 TFTP 伺服器運作。設定會持續保留直到變更，因此網路開機失敗時可重試並重新開機。預設情況下，等待 SSH 可用後，在 `netboot>` 提示字元輸入 `f` 進行燒錄。使用 `--autoflash` 時，選定裝置可連線且確認正執行網路映像後，就會開始燒錄。

```bash
sima-cli -i bootimg -v 1247 --netboot -f --devkit 192.168.2.2
```

## 處理 IP 位址變更

Linux 開機時，裝置可能取得不同位址。若 SSH 檢查一直等待舊位址，請在 `netboot>` 提示字元按 Ctrl+C。TFTP 伺服器會保持運作；使用 `q` 結束。

輸入 `d` 執行多播探索。若裝置未回應，請在另一個終端機使用 `sima-cli serial` 開啟序列主控台，並檢查 `ip -4 addr` 或 `ifconfig`。確認正確裝置與位址後，輸入 `f <ip>` 燒錄。探索不會自動選取燒錄目標。

## 準備燒錄 eMMC

寫入映像前，sima-cli 會列出所有由 eMMC 支援的已掛載檔案系統，包括 LVM 磁碟區與繫結掛載。釋放 LVM 對應前，會先卸載這些檔案系統。若掛載使用中、執行中的根檔案系統或啟用的交換空間使用 eMMC，或對應仍啟用，就會停止燒錄。請關閉使用這些檔案系統的程序，並從網路復原環境重試。卸載與映像寫入錯誤會停止燒錄，不會回報成功。
