# `sima-cli peripherals`

Show the cameras and microphones plugged into this DevKit.

Parent command: [`sima-cli`](./sima-cli.md)

## Usage

```bash
sima-cli peripherals <command>
```

## Options

None.

## Arguments

None.

## Subcommands

- [`sima-cli peripherals describe`](./sima-cli-peripherals-describe.md): Show one device in detail: every resolution and frame rate, and whether Neat can use it.
- [`sima-cli peripherals list`](./sima-cli-peripherals-list.md): Show the connected cameras and microphones.
