# `sima-cli cloudex devices`

Show NeatOps device availability and your allocation IDs.

Parent command: [`sima-cli cloudex`](./sima-cli-cloudex.md)

## Usage

```bash
sima-cli cloudex devices [OPTIONS]
```

## Options

| Name | Description |
