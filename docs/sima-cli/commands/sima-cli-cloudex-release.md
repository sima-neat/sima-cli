# `sima-cli cloudex release`

Release your NeatOps lease and disconnect its local CloudEx sessions.

Parent command: [`sima-cli cloudex`](./sima-cli-cloudex.md)

## Usage

```bash
sima-cli cloudex release [OPTIONS] ALLOCATION_ID
```

## Options

| Name | Description |
| --- | --- |
| `--environment` | (default: production) |

## Arguments

| Name | Description |
| --- | --- |
| `ALLOCATION_ID` | (required) |
