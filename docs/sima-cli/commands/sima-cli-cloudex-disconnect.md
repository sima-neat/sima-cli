# `sima-cli cloudex disconnect`

Disconnect one or all CloudEx sessions.

Parent command: [`sima-cli cloudex`](./sima-cli-cloudex.md)

## Usage

```bash
sima-cli cloudex disconnect [OPTIONS]
```

## Options

| Name | Description |
| --- | --- |
| `--session` | Session ID or unique prefix to disconnect. |
| `--all` | Disconnect every recorded CloudEx session. |

## Arguments

None.

## Full Help

```text
Usage: sima-cli cloudex disconnect [OPTIONS]

  Disconnect one or all CloudEx sessions.

Options:
  --session TEXT  Session ID or unique prefix to disconnect.
  --all           Disconnect every recorded CloudEx session.
  --help          Show this message and exit.
```
