# `sima-cli models branches`

List branches containing registered models.

Parent command: [`sima-cli models`](./sima-cli-models.md)

## Usage

```bash
sima-cli models branches [OPTIONS]
```

## Options

| Name | Description |
| --- | --- |
| `--stg, --staging` | Use the staging Model Registry unless SIMA_MODELS_REGISTRY_BASE_URL is set. |
| `--json` | Print machine-readable JSON. |

## Arguments

None.
