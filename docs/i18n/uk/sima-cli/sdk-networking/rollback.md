# Відмініть зміни мережевих налаштувань SDK.

Використовуйте функцію відкату, коли потрібно перевірити або скасувати зміни мережевих налаштувань хоста Linux, внесені під час налаштування SDK або відновлення мережі.

Відкат виконується з максимальною ефективністю. Він видаляє правила, які `sima-cli` може ідентифікувати для виявленого шляху DevKit/shared-network. Він не скидає не пов’язані мережеві налаштування хоста, конфігурацію VPN, стан встановлення Docker або правила брандмауера, якими керує користувач.

## Перегляньте дії, які буде виконано під час відкату.

Відкат виконується в режимі пробного запуску, якщо не вказано `--apply`:

```bash
sima-cli sdk network rollback --devkit <devkit-ip>
```

Перегляньте таблицю, перш ніж застосовувати зміни.

## Застосувати відкат.

```bash
sima-cli sdk network rollback --devkit <devkit-ip> --apply
```

Це видаляє відповідні правила перенаправлення/NAT, які застосовуються під час роботи, і які `sima-cli` додала для SDK-мосту та спільного мережевого шляху DevKit.

## Видаліть постійний профіль.

Якщо встановлено постійний профіль диспетчера NetworkManager, перед видаленням пропонуйте можливість скасування. Після повторного створення спільного з’єднання NetworkManager знову застосовуватиме перенаправлення SDK bridge, використовуючи цей профіль.

Щоб видалити його в інтерактивному режимі:

```bash
sima-cli sdk network rollback --devkit <devkit-ip> --apply
```

Щоб видалити його без взаємодії з користувачем:

```bash
sima-cli sdk network rollback --devkit <devkit-ip> --apply --remove-persistent-profile
```

Видалення збереженого профілю є безпечним, якщо ви хочете повністю скасувати відновлення мережевих налаштувань SDK. Якщо ви продовжуєте використовувати те саме спільне мережеве з’єднання Ubuntu DevKit, можливо, вам знадобиться повторно запустити процес відновлення пізніше.

## Після відкату.

Запустіть програму, щоб перевірити поточний стан:

```bash
sima-cli sdk doctor network --devkit <devkit-ip>
```

Якщо ви хочете повністю відновити мережеву конфігурацію SDK, виконайте команду:

```bash
sima-cli sdk setup --devkit <devkit-ip>
```

Для автоматизації, яка потребує постійного відновлення спільної мережі, використовуйте:

```bash
sima-cli sdk setup --devkit <devkit-ip> --persistent-network-profile -y
```
